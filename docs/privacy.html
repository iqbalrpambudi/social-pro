Privacy Policy for Social Pro

Last updated: October 2026

1. Information We Access

When you connect your YouTube or TikTok account, Social Pro accesses only minimal permissions needed to publish content:

  • Channel / Account name and unique identifier to identify destinations in your dashboard.
  • OAuth access and refresh tokens to authenticate publishing requests.
  • Video files, captions, and publication settings you explicitly select.

2. Data Storage & Protection

All data and media assets reside in your private self-hosted infrastructure. Access tokens are encrypted using AES-256-GCM. We do not sell or monetize your data.

3. Third-Party API Platforms

Media files are transferred directly to official platform endpoints (TikTok Content Posting API and YouTube Data API v3). We comply with the respective developer policies:

  • TikTok Privacy Policy
  • Google API Services User Data Policy

4. Data Revocation & Deletion

You can revoke access and delete all stored tokens at any time via the "Akun Terhubung" dashboard.
